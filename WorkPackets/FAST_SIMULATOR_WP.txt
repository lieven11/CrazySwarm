PURPOSE_BEGIN
Finish and qualify the existing deterministic Python simulator as the fast,
reproducible simulator for mission logic, safety, evidence, failure injection,
continuous real-time observation, offline development, and automated testing.

This simulator is not discarded when NVIDIA Isaac Sim is introduced. It remains
the fast test backend. Isaac Sim becomes the high-fidelity operator-facing backend
only after the separate NVIDIA work packets pass.
PURPOSE_END

BOUNDARY_BEGIN
- No physical drone, radio, deck, motion-capture system, or real flight is required.
- No value is described as measured hardware evidence.
- Physical coefficients remain CONFIGURED_UNQUALIFIED until later bench/flight data exists.
- The simulator may run in REALTIME for operator missions and ACCELERATED for tests.
- The browser never runs a flight-control loop or directly controls motors.
- Abort-and-land and emergency motor cutoff remain separate commands and evidence paths.
- DIGITAL_TWIN remains disabled without a qualified real adapter and measured reference.
- Fast-simulator qualification and release do not require an Isaac-capable host,
  paid cloud GPU, or successful NVIDIA runtime qualification.
BOUNDARY_END
