PURPOSE_BEGIN
Add NVIDIA Isaac Sim as the high-fidelity, operator-facing CrazySwarm simulation
backend before physical hardware is purchased. Preserve the current simulator as
the deterministic fast-test and fallback backend. Use one immutable mission,
vehicle, telemetry, safety, evidence, frame, and provenance contract across both.

This program builds a digital prototype and prepares the later digital-twin path.
It does not claim a true calibrated twin until real measured hardware telemetry
and an external reference become available in later hardware work packets.
PURPOSE_END

ARCHITECTURE_DECISION_BEGIN
INITIAL_RESOURCE_CONSTRAINED_DEPLOYMENT:
- The Mac runs the authoritative Control Center backend and safety supervisor,
  browser/operator UI, FAST_SIM, evidence, development tools, and mock gateway.
- The existing HP Victus Windows 11 laptop is the only planned local Isaac worker.
  It runs the live Isaac gateway, Isaac Sim, embedded PhysX, OmniGraph, and only the
  ROS 2 components required by the pinned Isaac release.
- The Victus is not a second independent Control Center or command authority. A UI
  opened there is another client of the single Mac-hosted supervisor.
- Browser/API communication uses the existing HTTPS/WebSocket boundary. The live
  simulator uses a separately authenticated, versioned gateway connection over a
  trusted local network.
- Network or worker loss must fail the affected simulation mission explicitly;
  it may never be converted to success or silently retried as a duplicate command.
- A future configuration may colocate the backend on a qualified Isaac host, but
  that is not required for the existing-hardware plan.
- `IsaacSimVehicle` talks to a versioned gateway; it does not import Isaac Sim's
  Python environment into the normal application virtual environment.

CANDIDATE_LOCAL_ISAAC_HOST:
- Model class: HP Victus Gaming Laptop, 15.6-inch FHD 144 Hz.
- Operating system: Windows 11 Home.
- CPU: Intel Core i5-13500H.
- System RAM: 16 GB DDR4.
- Storage: 512 GB SSD; available free space is unverified.
- GPU: NVIDIA GeForce RTX 4050 Laptop GPU; expected 6 GB VRAM must be verified locally.
- Qualification: CANDIDATE_EXPERIMENTAL_BELOW_CURRENT_DOCUMENTED_BASELINE.
- Current comparison recorded 2026-08-06: NVIDIA documents 32 GB system RAM and
  16 GB VRAM for the current minimum configuration. Requirements must be rechecked
  before installation because the supported release and baseline can change.
- No purchase, RAM upgrade, or paid cloud use is presumed. Any such decision is a
  separate optional user choice after measured compatibility evidence exists.

BACKENDS:
- FAST_SIM: existing deterministic Python simulator for CI, accelerated scenarios,
  failure sweeps, offline development, and cross-checks.
- ISAAC_SIM: default visible high-fidelity simulator after qualification.
- DIGITAL_TWIN: disabled until a qualified real adapter and measured reference exist.

COMMAND_AUTHORITY:
- The Control Center safety supervisor is the only high-level command authority.
- ROS 2/OmniGraph transports approved simulator commands and observations.
- Isaac Sim may never acquire authority to arm or correct a future real drone.
ARCHITECTURE_DECISION_END

SOURCE_OF_TRUTH_BEGIN
One canonical versioned parameter package supplies:
- vehicle variant, mass, center of mass, inertia, dimensions, rotor layout/direction;
- thrust/torque/actuator models, drag assumptions, controller limits, and battery;
- payload/decks and sensor poses, axes, rates, fields of view, noise, latency, limits;
- world/home/body/rotor/sensor frames, units, clocks, and transform conventions;
- room dimensions, obstacles, landing zones, materials where relevant, and lighting;
- model provenance, uncertainty, configuration hash, and qualification status.

The fast backend consumes a documented subset. The Isaac backend consumes the
same shared values plus USD geometry, collision, rendering, contact, and detailed
sensor configuration. Backend-specific values live in named sections and may not
silently override shared mission semantics.
SOURCE_OF_TRUTH_END
