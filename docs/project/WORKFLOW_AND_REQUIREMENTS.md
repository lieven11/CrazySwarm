# CrazySwarm workflow and requirements

The monolithic requirements document was split into selectively loaded, single-authority files. Start with the [requirements index](requirements/README.md), which routes each task to only the relevant domain and workflow documents.

All 147 stable requirement IDs and their wording were preserved. Historical design decisions, retrospectives, and the feedback changelog now live in their own non-normative files linked by the index. This compatibility page contains no normative requirement definitions.
